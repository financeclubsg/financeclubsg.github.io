# Stock Pitch Tracker · Finance Club Singapore

**https://financeclubsg.github.io/**

The hypothetical performance of every stock pitch Finance Club Singapore posts on LinkedIn: what we would have made if we had followed each call, compared with the S&P 500.

- New pitches are added automatically from the club's LinkedIn page.
- Prices come from Yahoo Finance and refresh several times a day.
- Hypothetical performance, for educational purposes only. Not investment advice.

## Want to change something?

1. Send your GitHub username to Nicolas to get access.
2. Propose your change in a **pull request**. Never edit `main` directly.
   - **Small edit:** open the file on github.com, click the pencil, make your change, then choose *"Create a new branch and start a pull request"*.
   - **Bigger change with Claude:** ask it to *"clone https://github.com/financeclubsg/financeclubsg.github.io, make these changes: …, show me a preview, then open a pull request"*. Claude follows the rules in [`CLAUDE.md`](CLAUDE.md).
3. A few minutes later, Netlify comments on your pull request with a **Deploy Preview** link. Anyone can open it to see the site with your change.
4. Nicolas reviews and merges it. The live site updates about a minute later.

See [`CLAUDE.md`](CLAUDE.md) for how the project works and the rules to follow.
