Méthode

  • Chaque pitch publié sur la page LinkedIn du club est suivi automatiquement.
  • Prix d'entrée : le cours de clôture de la première séance qui suit la publication du post (le jour même si le post sort avant la clôture).
  • BUY = achat ; SELL = vente à découvert (on gagne si le cours baisse). La position est gardée jusqu'à la fin de l'horizon annoncé, puis figée.
  • Rendements dividendes compris, dans la devise de chaque action (sans effet de change).
  • Chaque pitch est comparé à l'indice de son marché (DAX pour l'Allemagne, STI pour Singapour, S&P 500 pour les États-Unis…).
  • Données de cours : Yahoo Finance.

Performance hypothétique, à but éducatif uniquement. Ce n'est pas un conseil en investissement.
